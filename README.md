**Projects Included**

**1. Calculator**
A web-based calculator that performs basic arithmetic operations.

**Features**
- Display screen for input and results
- Number buttons (0–9)
- Operation buttons (+, −, ×, ÷)
- Clear button to reset
- Equal button to calculate result

**Technologies Used**
- HTML
- CSS
- JavaScript

---

**2. Temperature Converter**
A tool that converts temperature values between Celsius and Fahrenheit.

**Features**
- Input field for temperature value
- Toggle between °C → °F and °F → °C
- Convert button
- Reset button

**Technologies Used**
- HTML
- CSS
- JavaScript

---
**How to Run the Projects**

1. Download or clone this repository
2. Open the project folder
3. Double-click the HTML file (e.g., `index.html`) to open in a browser
