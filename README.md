Portfolio Website
A personal portfolio website showcasing skills, projects, and contact information.

Features
- About Me section
- Technical Skills display
- Projects showcase
- Education details
- Contact section with LinkedIn & GitHub links

Technologies Used
- HTML
- CSS

How to Run the Projects

1. Download or clone this repository
2. Open the project folder
3. Double-click the HTML file (e.g., `index.html`) to open in a browser

Purpose

These projects were created as part of academic assignments to practice:
- Web page structure
- Styling and layout design
